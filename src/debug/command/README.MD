# 除錯主控臺

PIXMINO 除錯主控臺，用於遊戲除錯

---

## [REPL] SHELL

用於用於命令輸入迴圈，解析命令輸入，呼叫對應的命令

內建命令: 

| 命令 | 含義         |
|--------|--------------|
| `?`    | 獲得命令列表 |
| `EXIT` | 退出         |
| `PID`  | 獲得進程 ID  |

---

## CLS

清空主控臺

用法: `CLS`

---

## CURSOR

顯示游標高度

用法: `CURSOR <高度>`

---

## ENTER

啟動指定模式並離開主控臺

用法: `ENTER <模式>`

---

## [REPL] LUA

啟動 Lua REPL

用法: `LUA`

---

## SAVE

檢視或修改存檔（危險命令）

用法: `SAVE <模式> <選項>`

| 選項 | 用法                | 含義                 |
|----- |--------------------|----------------------|
| `/U` | `/U <KEY> <VALUE>` | 更新或建立鍵值       |
| `/D` | `/D <KEY>`         | 刪除鍵值             |
| `/L` | `/L`               | 從磁碟重新載入       |
| `/F` | `/F`               | 將設定寫入磁碟       |

---

## UNLOCK

解鎖危險命令限制

用法: `UNLOCK <選項>`

| 選項 | 用法      | 含義 |
|------|-----------|------|
| `/U` | `/U`      | 回鎖 |

---

## VER

顯示遊戲版本

用法: `VER`
